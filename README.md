## Operating Thesis

<div align="center">

<img src="./assets/revenue-loop.svg" width="92%" alt="Revenue operating system: Signal, Sense, Decide, Execute, Learn" />

</div>

Every layer should make the next layer smarter. **Insight becomes action. Action creates better data. Better data improves the next decision.**

| Stage | Role |
|:---:|:---|
| **Signal** | Capture market, customer, channel, and behavioral inputs |
| **Sense** | Connect data, context, patterns, and anomalies |
| **Decide** | Diagnose, prioritize, and recommend action |
| **Execute** | Activate campaigns, sales motions, workflows, and automation |
| **Learn** | Turn measurement and feedback into reusable commercial intelligence |

## Principles

| | Principle | Operating belief |
|:---:|:---|:---|
| **01** | **Systems over tactics** | A tactic can create a spike. A system creates repeatability, feedback, and resilience. |
| **02** | **Decisions over dashboards** | Analytics is useful when it changes what a team understands, prioritizes, or does. |
| **03** | **Context before automation** | Automating a weak process only makes the weakness run faster. |
| **04** | **Commercial + technical** | The best solutions respect business outcomes and implementation reality. |
| **05** | **Clarity creates speed** | Clear ownership, definitions, and measures remove operating friction. |
| **06** | **Reusable intelligence** | Every experiment should improve the next one through insight, structure, or IP. |
